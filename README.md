# داشبورد تحلیل حساسیت طلا، نقره، مس و روی

ماتریس حساسیت قیمت (دلار آزاد × قیمت جهانی) و ماتریس حباب برای:
طلای ۱۸ عیار، مظنه، نقره ۹۹۹، گواهی سپرده شمش نقره،
گواهی سپرده مس کاتد و گواهی سپرده شمش روی.

## اجرا
```bash
pip install -r requirements.txt
streamlit run app.py
```

## تست
```bash
pip install -r requirements-dev.txt
pytest
```

## معماری
- `metals_whatif/core`: منطق محاسباتی خالص (فقط numpy، بدون Streamlit)
- `metals_whatif/ui`: ورودی‌ها، نمودارها و تب‌ها
- `app.py`: اتصال core به ui


## فرض‌های مدل
- هر گواهی مس/روی = ۱ کیلوگرم؛ ارزش = `LME × دلار × (1+α) / 1000`
- هر گواهی نقره (CD1SIB0001) = ۱ گرم؛ ارزش = `(انس نقره ÷ 31.1034) × دلار × (1+α)`
- گواهی نقره از محور انس نقره مشترک با نقره خام استفاده می‌کند، اما پریمیوم α آن مستقل از «حباب نقره خام» است.
- مالیات و کارمزد (در صورت فعال بودن) به‌صورت ضریب جمعی `1 + (VAT + fee)/100` اعمال می‌شوند. پیش‌فرض VAT برای مس و روی ۱۰٪ و برای گواهی نقره ۰٪ است.
- هزینه انبارداری و هزینه ارزیابی تحویل فیزیکی در مدل نیست.
- قیمت‌ها به تومان‌اند (قیمت تابلوی بورس کالا ریال است؛ بر ۱۰ تقسیم شود).
